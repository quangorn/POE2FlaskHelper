# POE2FlaskHelper — backlog

## Окно настройки конфига (отложено)

Placeholder-окно не делается. В будущем на его месте появляется окно настройки
приложения.

Планируется:

- небольшое окно поверх всех окон, показывается/скрывается глобальным хоткеем
  (хоткей добавляется в конфиг вместе с фичей);
- живой вывод текущих процентов Vital'ов и статуса сканера/подключения к игре;
- редактирование конфига через UI вместо ручной правки `config.json`:
  - хоткей переключения сканера (валидация: модификатор или F-клавиша, проверка
    конфликтов);
  - для каждого Vital: `enabled`, `key`, `threshold`, `cooldownMs`;
  - `scanner.pollIntervalMs`, `scanner.requireGameForeground`,
    `scanner.enabledOnStart`;
  - уровень логирования;
- кнопки Save / Apply / Reload, валидация полей, подтверждение при некорректных
  значениях;
- применение настроек на лету: перерегистрация хоткея, перезапуск потока сканера при
  смене `pollIntervalMs`, перечитывание `offsets.json`;
- сохранение позиции окна рядом с exe (в том же каталоге конфигов);
- portable-раскладка сохраняется: конфиг и логи лежат рядом с исполняемым файлом.

Ограничения проекта:

- UI, включая это окно, остаётся на главном потоке (GDI/message loop); сканер
  сохраняет отдельный рабочий поток;
- никаких сторонних UI-библиотек, только нативный Win32.

Статус: отложено.

## Громкость WAV (отложено)

Одна настройка на все проигрываемые файлы (`enable.wav` / `disable.wav`); отдельная
громкость на каждый файл не делается. Реализация решена: **модификация аудио в памяти**
(вариант 1), системная громкость не трогается.

- `config.json`: секция `"sound": { "volume": 100 }`, значение 0–100, по умолчанию 100;
  невалидное — warning в лог и значение по умолчанию (правила SPEC §5); добавляется в
  `config_serialize` (файл первого запуска), SPEC §5 и README.txt;
- применяется при старте: файл читается один раз на старте, как все настройки
  (§4.1/§5), правка `volume` требует перезапуска;
- `PlaySoundW` громкость не умеет (флагов громкости у `SND_ASYNC`/`SND_SYNC` нет). Путь:
  WAV-ресурс читается в память (`FindResource`/`LoadResource`), PCM16-семплы
  масштабируются коэффициентом `volume/100` с сохранением формата (8/16/24-bit и
  non-PCM играются без масштабирования), проигрывание через
  `PlaySoundW(ptr, NULL, SND_MEMORY | SND_ASYNC | SND_NODEFAULT)`;
- ассеты `res/enable.wav` / `res/disable.wav` уже PCM16 — масштабирование применимо к
  обоим, перекодирование не нужно;
- масштабирование выносится в чистую функцию ядра (формат-разбор WAV-чанков +
  масштабирующая функция на int16-массиве), тестируется на синтетическом PCM-буфере
  без Win32 (§3.1);
- тесты: валидация `volume` в `config_tests.cpp` (0, 100, границы, отрицательное,
  не-число, неизвестный ключ секции), масштабирование (0 → тишина, 100 → побайтно
  тот же буфер, округление семплов, клиппинг), разбор non-PCM fmt-чанка → без
  масштабирования;
- границы: `volume: 0` — играется тишина (клиппинг к 0), звук переключения формально
  остаётся; warning при битом WAV уже описан (§8), путь `SND_MEMORY` его наследует.

Статус: отложено.
