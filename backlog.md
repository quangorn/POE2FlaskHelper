# POE2FlaskHelper — backlog

## Окно настройки конфига (отложено)

Placeholder-окно не делается. В будущем на его месте появляется окно настройки
приложения.

Планируется:

- небольшое окно поверх всех окон, показывается/скрывается глобальным хоткеем
  (хоткей добавляется в конфиг вместе с фичей);
- живой вывод текущих процентов Vital'ов и статуса сканера/подключения к игре;
- редактирование конфига через UI вместо ручной правки `config.json`:
  - хоткей переключения сканера (валидация: модификатор или F-клавиша, проверка
    конфликтов);
  - для каждого Vital: `enabled`, `key`, `threshold`, `cooldownMs`;
  - `scanner.pollIntervalMs`, `scanner.requireGameForeground`,
    `scanner.enabledOnStart`;
  - уровень логирования;
- кнопки Save / Apply / Reload, валидация полей, подтверждение при некорректных
  значениях;
- применение настроек из окна: hot-reload `config.json` (5 с цикл, живые параметры,
  SPEC §5) уже делает это для правок файла, окно добавляет сохранение и применение из
  UI; перезапуск потока сканера при смене `pollIntervalMs` и перечитывание
  `offsets.json` остаются планом окна (`offsets.json` по-прежнему читается только на
  старте, plan.md §4 с amendment 2026-11-08);
- сохранение позиции окна рядом с exe (в том же каталоге конфигов);
- portable-раскладка сохраняется: конфиг и логи лежат рядом с исполняемым файлом.

Ограничения проекта:

- UI, включая это окно, остаётся на главном потоке (GDI/message loop); сканер
  сохраняет отдельный рабочий поток;
- никаких сторонних UI-библиотек, только нативный Win32.

Статус: отложено.

Реализованное: «Громкость WAV» сделана 2026-11-08 (`sound.volume` 0–100, масштабирование
PCM16 в памяти на каждое проигрывание, SPEC §4.5/§5) и из backlog вынесена.
Hot-reload `config.json` сделан 2026-11-08 планом
[`plan-hot-reload.md`](plan-hot-reload.md) (выпуск 1.2.0): 5 с цикл со штампом
`LAST_WRITE`+size, живые параметры применяются на лету (таблица SPEC §5), restart-only
поля с warn «applies after restart», `reload.wav` только на успешный parse+apply и не на
старте — из backlog вынесён. Окно настройки конфига через UI остаётся отложенным;
`offsets.json` hot-reload (перечитывание) живёт здесь, в плане окна (§7 плана
